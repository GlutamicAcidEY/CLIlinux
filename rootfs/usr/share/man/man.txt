MAN(1)                  CLIlinux Manual                  MAN(1)

NAME
    man - display manual pages

SYNOPSIS
    man COMMAND

DESCRIPTION
    Display the manual page for a command.

    Manual pages are stored in /usr/share/man/.

EXAMPLES
    man ls
        Display the manual page for ls.

    man cat
        Display the manual page for cat.

    man man
        Display this manual page.

FILES
    /usr/share/man/
        Directory containing CLIlinux manual pages.

ERRORS
    If a manual page does not exist, man prints the following
    error message: man: COMMAND not found 

SEE ALSO
    ls(1), cat(1)
