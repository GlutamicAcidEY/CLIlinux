NAME
    ls - list directory contents

SYNOPSIS
    ls [OPTIONS] [PATH]

DESCRIPTION
    List information about files and directories.

OPTIONS
    -a
        Show all files.

    -l
        Use long listing format.

EXAMPLES
    ls (list [] [. (cwd)]
    ls /etc (list [] [/etc]
    ls -la /etc (list [long, all,] [/etc]
